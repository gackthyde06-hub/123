V2.6.24 — System Growth Status / Quest UI

這版只動「系統養成」的前端呈現，不改交易門檻、Shadow 學習參數、通知設定、實際建倉、Railway Variables 或 Volume。

主要改善
- 移除 V2.6.23 不一致的大型裝飾圖片與貼圖感。
- 所有圖示改成同一套 inline SVG 線框語言，避免風格衝突與圖片重疊。
- 配色收斂為黑曜石 / 香檳金 / 冷藍，金色只強調當前與已驗證，藍色只給 Forward/OOS。
- 系統養成打開後直接像角色狀態欄：目前階段、成熟度、Train Net PF、Forward OOS。
- 角色狀態：方向辨識、執行品質、成本效率、Regime 適應、穩定度、風險過濾。
- 成長進度：樣本收集 → 校準 → OOS 驗證 → Edge 穩定 → 實戰成熟。
- 主線任務：A 級泛化、成本後 Edge、Forward OOS。
- 每日訓練：直接顯示後台現在在做什麼。
- 最近成長紀錄：只記錄真正數據變化，不堆假日誌。
- 下一階解鎖條件：有效樣本、Forward OOS、穩定窗口。
- 不再顯示「導師評語」。
- 小鎖固定在「系統養成 / Lv」同一排最右側。
- 手機採 2x2 summary、3x2 能力格、任務單欄；完全避免元素重疊。
