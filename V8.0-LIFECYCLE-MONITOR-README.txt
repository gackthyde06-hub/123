V8.0 回踩生命週期監控

- 保留原本三位交易員監控。
- 測試訊號成立後不停止判讀，持續追蹤：強勢 / 續強 / 轉弱 / 轉強 / 失效。
- 小狀態標籤放在幣種名稱旁，監控判讀與測試頁都可直接看到。
- 突破：需兩根已收 5 分 K 站上/站下結構位，降低單根插針誤判。
- 轉弱：多條件（突破位、RSI、MACD、主動買賣、大戶持倉、15分結構、BTC/ETH 大盤）且連續確認。
- 轉強：轉弱後重新收復結構並恢復動能才解除警戒。
- 結構失效：突破後保護位連續失守才判死；不是碰一下就失效。
- 推播生命週期：回踩成立、突破續強、轉弱警戒、重新轉強、1R 達成、訊號/結構失效。
- 所有測試訊號通知點擊只回「監控 → 回踩判讀」，不直接開 TV。
- 監控判讀保留全部展開 / 全部縮小，多筆仍依可用勝率排序。
- 額外加入 Binance Futures 大戶持倉多空比與全市場多空比作為輔助，不單獨決定方向。
- 監控頁開著時每 30 秒同步一次測試訊號狀態；後端預設每 60 秒掃描。
