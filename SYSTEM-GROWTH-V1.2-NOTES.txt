SYSTEM GROWTH v1.2.1 — 2026-09-01

定位：V10.2.7 的純 UI / 閱讀 / 養成層。沒有修改交易訊號、通知門檻、Shadow Learning、State Learning、C-mode 或實際建倉邏輯。

本版重點
1. 手機優先：觸控目標 >= 44px、單欄候選詳情、2/1 欄技能卡、降低手機陰影/動畫與背景負擔。
2. 今日探索 3 步：今日一課 / 拆候選 / 模型日誌。只記閱讀進度，不加系統 XP、不影響模型。
3. 動態「今日一課」：依目前樣本數、PF、命中與 BLOCKED 狀態，自動選最值得理解的觀念。
4. 研究階段：探索期 → 校準期 → 驗證期 → 穩定期 → 深化期，以去相關有效樣本推進。
5. 候選可展開：直接看已具備、還在等、校準值、通知分數、市場狀態，以及「怎麼看」。
6. 技能樹精緻化：初階 / 進階 / 熟練 / 專精 / 大師；顯示下一階還差多少樣本。
7. 研究手冊：45 分去相關、PF、MFE/MAE、狀態學習，全部用系統本身語境解釋。
8. 研究足跡：本機保存近 14 日快照，顯示近 7 日 XP 成長曲線。
9. 成就與里程碑：只獎勵研究、過濾、等待，不獎勵交易次數。
10. AI 情報：仍是手動按下才網搜，2 小時快取，避免背景燒 API。
11. 視覺：保留原 APP 黑金；加入極少量藍寶石節點與細框，偏主機 JRPG / HD-2D 成長介面，不做手遊感。

研究設計原則
- 主要資訊先看懂，次要資訊用展開（progressive disclosure）。
- 即時回饋用來解釋進度，不用來催促交易。
- 遊戲化支援「能力感 / 自主探索 / 清楚目標」，避免把交易次數當獎勵。
- 今日探索是閱讀導覽，不是模型數據；系統 XP 仍只由真實研究資料構成。


READABILITY HOTFIX v1.2.1
- Desktop and mobile typography enlarged substantially.
- Mobile micro text is no longer 7–9px in most core areas.
- Candidate, lesson, skill, journal, manual, and intel text moved up one readability tier.
- On <=420px phones, skill cards switch to one column to protect legibility.
- Trading / notification / learning logic remains untouched.
