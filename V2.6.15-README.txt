V2.6.15 — UI 穩定化 + 影子 A/B 通知去重

這版處理 V2.6.14 的根因，不再用每 4 秒輪詢去隱藏/顯示 UI。

修正：
1. 實際建倉
   - 觀察頁只留一個「實際建倉 / 顯示」開關，預設關閉。
   - 打開後會一直保持打開，不會幾秒後自己消失。
   - 已建倉區右上 × = 關閉顯示，不會結案、不刪資料。
   - 結案仍由卡片內「結案」處理。

2. 觀察資料新鮮度
   - 後端觀察候選只保留最近 5 分鐘更新資料。
   - 前端再保險隱藏超過 4 分鐘的舊卡。
   - 真正已通知的監控歷史仍保留，不影響績效/學習。

3. 建議 / 影子 A/B
   - C、ALL 不再靠 4 秒計時器隱藏；每次 DOM 更新當下就移除，避免閃一下又消失。
   - 若舊版曾停在 C/ALL，自動切回 A；A 沒候選但 B 有候選時，自動顯示 B。
   - 只保留影子 A、影子 B。

4. 通知
   - 手機推播仍只保留：熬鷹建倉/加碼/減碼/平倉 + 影子 A/B。
   - 手動 / 自動 / 全開三種來源模式。
   - 新增伺服器端 10 分鐘跨來源去重：同一 A/B、同標的、同方向，手動與自動不會各響一次。
   - Daily Brief、其他交易員、回踩狀態、共識、失效狀態不會成為手機推播。

5. UI 穩定性
   - 移除 V2.6.14 的 4 秒 UI tick。
   - 改用 childList MutationObserver；不監看 class/attribute，因此不會形成無限 Mutation loop。
   - app cache key 更新至 102615；v2615-stability.js 使用獨立 cache key 2615。

不變：Railway Variables、Volume、Shadow/ABC 學習資料、實倉歷史、績效帳本。
