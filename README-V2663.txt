候選邏輯
- 正式 A / B 原本規則完全保留，不因候選而放寬。
- 候選只從目前前 12 名中挑選原本仍是 C 的標的。
- 候選分數使用：
  校準勝率 + Shadow 相關累積樣本命中率/PF + 執行分 + 排名分 + 結構健康 + 資料完整/可信度。
- 候選最低門檻：
  影子共識分 >= 67
  候選勝率 >= 58%
  且 Shadow 相關樣本 >= 8，或校準勝率 >= 62%
- BLOCKED、硬阻擋、結構 DESTROYED、RR<1、終止 tracker、已有 ACTIVE 實倉都不能成為候選。
- 寧可候選為 0，也不補低品質標的。

防跳動 / 防一下出現一下消失
- 新候選必須連續通過 2 次掃描才會進欄位。
- 入選後至少保留 20 分鐘。
- 20 分鐘內只有「硬失效」才立即消失。
- 暫時一個掃描沒抓到，可保留最多 8 分鐘，不會立刻閃掉。
- 20 分鐘後若要被替換，新候選的影子共識分必須至少高 6 分。
- 候選 UI 自己 60 秒更新一次，且順序以入選時間穩定，不會每次分數微動就洗牌。

展開候選會直接看到
- 為什麼影子目前把它列為最有機會
- 影子相關樣本、命中率、PF、校準勝率、共識分
- 離正式 B 還差什麼
- 離正式 A 還差什麼
- 如果現在硬要打，要注意什麼
- 參考成本、進場區、TP1/TP2、SP
- 可直接填保證金/槓桿並建立候選實倉追蹤

重要
- 候選不是正式通知。
- 候選永遠不會因為 candidate=true 自動送出進場通知。
- 如果你真的從候選手動建倉，實際結果仍會送進 actual-trades 紀錄，供後台後續統計/學習。
