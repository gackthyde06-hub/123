V2.6.12 — CRYPTO + US STOCK PERP LEARNING / DUAL MARKET UI
Date: 2026-09-02

延續 V2.6.11。這版重點是「幣圈與美股永續一起觀察、各自學習、最後安全吸收共同經驗」，同時重整今日 / 流向 / 建議排名的 UI。

1) 幣圈 / 美股雙市場
- 今日新增：幣圈 / 美股切換。
- 流向新增：幣圈 / 美股切換。
- 建議排名新增：全部 / 幣圈 / 美股切換。
- 美股永續不再被高成交量幣圈標的完全擠掉；候選池保留美股名額。
- 內建常用美股 / ETF 對應資料：MSTR、COIN、CRCL、PLTR、NVDA、AAPL、MSFT、AMZN、META、TSLA、GOOGL/GOOG、AVGO、AMD、TSM、NFLX、MU、INTC、SPY、QQQ、IWM、DIA、BITO。

2) 高勝率 / 普通 / A-B-C 都可涵蓋美股
- 美股永續沿用既有 HIGH / NORMAL 通知流程、風險閘門與監控頁。
- A / B / C 手動作戰清單改為幣圈與美股平衡取樣，避免只剩幣圈。
- ABC Shadow 同樣記錄美股樣本，無須實際下單也能累積結果。
- 通知白名單維持 V2.6.11：只留可執行通知，不恢復轉弱/續強/失效等噪音。

3) 全部學習，但不把兩個市場硬混在一起
- 新 Shadow 樣本記錄 assetClass / assetSession / assetFamily。
- 學習優先順序：同市場＋同時段＋同策略狀態 -> 同市場較寬條件 -> 同市場策略狀態。
- 同市場樣本不足時，才使用跨市場共同結構經驗，而且限制為低權重 ±1 分的大樣本備援。
- Actual Trade 真實建倉回饋只在同市場證據內加減分。
- ABC Shadow 也遵守同市場優先；跨市場只作弱參考。
- 原本 45 分鐘去相關、最低樣本門檻、硬阻擋條件全部保留。

4) 美股時段記憶
- 美股樣本額外記錄：盤前 / 正規盤 / 盤後 / 隔夜 / 週末。
- 幣圈則維持 CRYPTO_24H。
- 相同策略在 NVDA 正規盤與 BTC 24H 不會直接當成同一個完整樣本群。

5) 美股風險資料改成適合美股永續的判讀
- 美股使用自己的美股永續廣度做大盤方向，不再用 BTC/ETH 當市場羅盤。
- 美股不強制要求 Bybit / OKX 跨所資料、大戶多空等幣圈專屬欄位才能進 HIGH / NORMAL。
- K 線、OI、Taker、Depth、Funding、Mark、回測與美股市場廣度仍保留。
- 幣圈原本 Binance + Bybit + OKX / BTC-ETH 大盤條件不變。

6) 建議排名資訊加厚，但公開資訊不亂燒
- 每張卡先顯示本機中文背景：類型、用途、歷史、風險、參考市場，以及量化估算 / 排名分 / 歷史1R / OI / Taker。
- 原本「公開資訊 / 中文整理」改成卡片最右邊只有「展開」兩字。
- 只有使用者真的展開時才補公開資訊。
- 公開資訊快取由 2 小時拉長到 6 小時；量化行情仍按原本頻率更新。
- 公開資訊失敗不影響排名、Shadow、通知或監控。

7) UI
- 延續黑金主視覺；美股使用低飽和藍色識別，幣圈保留金色識別。
- 手機雙欄資訊重新縮排，資產切換使用圓角小按鈕。
- 建議 / 觀察 / 監控的標的旁顯示「幣圈 / 美股」小標籤。
- PF 無虧損 sentinel 仍顯示「無虧損」，不顯示 PF 99.00。

不變項目
- 不刪 Railway Volume。
- 不重建資料庫 / Shadow 歷史。
- 不取消 HIGH / NORMAL 原硬阻擋。
- 不改交易員 OPEN / ADD / REDUCE / CLOSE 通知。
- 不恢復已關閉的狀態噪音通知。
- 不讓重型回測卡住即時通知主迴圈。

部署
