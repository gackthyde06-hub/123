V6.5 PULLBACK RADAR

用途
- 熬鷹資本建倉後，由後端自動追蹤，不需要一直開著 App 或 TradingView。
- 收到一般回踩、深度回踩或過深／失效通知後，點通知直接開該標的 TradingView，再由使用者判斷 SMC、POC 與是否下單。

準確性規則
1. 只接受訂單 API 的 OPEN 紀錄作為精確首次進場價與時間。
2. 訂單 API 不是 OK、首次進場無法精確對上、歷史極值尚未補齊時，一律不發回踩通知。
3. 先要求價格走出「0.8% / 0.75 倍 15 分 ATR，取較大者」，最高以 3% 啟動門檻封頂，避免成本附近普通震盪被誤報。
4. 以首次進場到建倉後有利極值作動態斐波：38.2% 一般回踩、61.8% 深度回踩、78.6% 回踩過深。
5. 同時保存建倉當下的 15 分結構失效參考；觸及時發結構失效通知。
6. 每一筆倉位每個階段只提醒一次；若直接穿越多個階段，只發當下最嚴重的一級。
7. 伺服器重啟後會用 Binance K 線補回中斷期間的有利極值，再恢復監控。

更新方式
- ROOT 壓縮檔：放到 Railway 專案根目錄。
- PUBLIC 壓縮檔：放到 Railway 專案 public 目錄。
- 部署完成後，在 iPhone 桌面 App 打開「通知設定」，按一次「同步 iPhone 通知」。
- 確認「回踩」「深回踩」「過深/失效」三個通知類型已開啟。
- 可按「測試回踩通知 → 開TV」確認推播與 TradingView App 喚起；iPhone 會優先直接開啟已安裝的 App，不再先轉網頁版。
- 倉位下方的回踩狀態改成兩行：第一行只顯示「回踩」，第二行顯示目前監控狀態，已移除小圖案與「雷達」字樣。

重要
- 回踩通知只負責叫你回來看盤，不是進場訊號。
- App 無法讀取你在 TradingView 手動畫的 SMC／POC；最後仍以 TV 盤面確認。
- 建議保留 Railway Volume，避免 VAPID、訂閱與回踩追蹤狀態在重建時遺失。
