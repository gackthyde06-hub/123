V2.6.23 — Existing System Growth RPG Polish

這版不是重做「系統養成」，而是直接強化現有介面。

保留：
- 現有系統養成開關 / Lv / XP / 雷達 / 成長階段 / 章節 / 原本黑金 UI。
- V2.6.22 Shadow Mentor、Forward OOS、High Edge 手動觀察。
- 建議/監控/觀察獨立鎖、TV 返回、防抖、實際建倉、通知設定。
- 所有交易門檻、Shadow 門檻、通知與 Railway Variables 全部不改。

本版只做：
1. 現有核心卡增加低干擾晶核徽章，不換版型。
2. 現有成長階段圓點改成 RPG 階段徽章；原本階段流程仍相同。
3. 現有六維雷達下增加對應技能小圖示與目前數值，雷達本身保留。
4. V2.6.22 的「影子訓練體檢」合併回現有核心卡，拿掉外面重複的一塊。
5. 顯示 Train Net PF / Forward OOS / 穩定窗 / Top2 集中度 / 最強 Edge / Mentor 評語。
6. 鎖仍位於系統養成 + Lv 同一排最右側。

核心原則：
RPG 圖只是可視化；不會因為圖、Lv 或 XP 自動放寬交易條件。
