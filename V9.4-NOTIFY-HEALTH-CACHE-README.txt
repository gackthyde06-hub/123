V9.4 — 嚴格通知診斷 / AI 2 小時快取標示 / API 共用快取

1. 「高＋普通」通知門檻維持嚴格，不為了增加通知量而放寬：
   - 高勝率：校準勝率 >= 68%、保守下界 >= 50%、品質 >= 87、當日排名前 6、追價 <= 0.18 ATR。
   - 普通：校準勝率 >= 60%、保守下界 >= 43%、品質 >= 80、當日排名前 9。
   - 兩者都必須無 15m/30m/1h/大盤逆向、價差過大、追價、ADL 高風險、Funding 擁擠、轉弱/失效。
2. 測試頁新增通知診斷：每顆會顯示「高勝率通過 / 普通通過 / 未達普通原因 / 暫停原因」。
3. 測試頁通知區顯示目前高 / 普通 / 有效 / 暫停數量，方便確認「通知少」是因門檻嚴格，而不是系統沒有掃描。
4. 新增簡潔系統健康列：最近掃描、延遲/過期數、監控數、共用快取狀態。
5. 詳細分析旁顯示「AI網搜 · 2小時快取」；第一次完成後 2 小時內同標的不再重複呼叫 OpenAI。
6. 詳細內容顯示快取剩餘時間；即時 Binance 量化仍持續更新。
7. Binance Futures OI / 主動買賣 / 大戶比 / 全市場多空加入 25 秒共用快取，降低同一輪重複 API 請求。
8. 修正推播可靠性：若本來符合通知但 Web Push 傳送失敗，不再誤記為「已通知」，下一輪仍可重試。
9. 展開狀態持久化、名稱開 TradingView、監控/達標池/二次回踩等既有 V9.3 邏輯保留。

注意：高＋普通通知本來就應偏少。V9.4 的目標是提高可解釋性與可靠性，不是增加訊號數量。
