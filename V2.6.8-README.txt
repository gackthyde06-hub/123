V2.6.8 UI 精修更新

本版只修 UI / 回到畫面定位 / 影子歷史顯示，不放寬交易通知門檻，也不刪除既有學習資料。

1. TradingView 返回定位
- 點標的名稱照舊另開 TradingView 網頁版。
- 離開 APP 前記住目前頁籤、捲動位置與被點擊的 TV 連結位置。
- 關閉 TV 回 APP 後會重新釘回原本那一列，並補償背景 refresh 造成的卡片高度變化。
- 若你回 APP 後主動滑動，定位保護會立刻解除，不跟你搶畫面。

2. 系統養成
- 「ABC 戰術養成」改名「影子戰術」。
- 影子戰術內的「正在發生」同步改成「篩選中」。

3. 結構記憶圖示
- 複雜圖章/框/背景全部拿掉。
- 改成單純「◇」菱形，無框、無背景、無陰影。

4. 手動模式：Shadow 歷史與 SAMPLE 明細
- A / B / C 的「X SAMPLE」卡片現在可以展開。
- 展開後顯示最近哪些標的實際進入該級可學習 SAMPLE。
- 新增「歷史」展開列，列出最近進入 ABC Shadow 的標的。
- 歷史顯示：最多 30 筆、近 360 分鐘（6 小時）。
- 每個 A/B/C SAMPLE 明細：最多 12 筆、近 360 分鐘（6 小時）。
- 6 小時後只從 UI 明細自動消失；Shadow 統計、SAMPLE 數與模型學習紀錄不刪除。
- 歷史 API 採「展開才抓」＋前端 60 秒快取，避免為了 UI 額外一直燒 Railway Egress。

5. B 級藍色
- B 級仍保留藍色辨識。
- 左側亮線再降亮度、縮成 2px，避免太搶眼。

版本：V2.6.8
