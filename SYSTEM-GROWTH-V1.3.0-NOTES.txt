SYSTEM GROWTH UI v1.3.0 — PERSONAL PROGRESSION POLISH

目的
- 個人使用優先：刪除過度解釋與顯而易見的小對話。
- 保留必要提示，詳細內容只在展開時出現。
- 讓研究資料更像主機 RPG 的成長介面，而不是教學頁或手遊。
- 不改 V10.2.7 交易判斷、通知門檻、Shadow Learning、State Learning、C Mode。

主要更新
1. 今日探索 → 今日章節：解析 / 候選 / 日誌，以三節點任務線呈現。
2. 今日一課 → 今日解析：收合時只看主題與當前數據；展開才看重點。
3. 候選詳情刪除多餘教學語句，改成校準 / 評分 / Regime / 已成立 / 待確認。
4. 技能卡文案縮短，保留研究含義與真實樣本進度。
5. 模型日誌 / 足跡 / 成就 / 資料庫 / 情報 / 成長規則改成較像遊戲資料庫的短標籤。
6. 增加研究核心幾何徽記、雷達光暈、技能樹連線、成就幾何章、資料庫圖騰等純 UI 裝飾。
7. SYSTEM / 研究階段 / 技能升階時，使用真實資料觸發一次性升階提示。
8. 增加小型浮動 ↑ / ↓：快速回最上 / 最下，不佔版面。
9. 手機版今日章節改為 3 節點橫列，技能樹維持單欄閱讀。
10. Cache key 更新 sg130。

互動原則
- 成長回饋來自真實研究樣本，不用交易次數刷經驗。
- 沒有無限捲動、隨機寶箱、倒數焦慮等賭場式 dark pattern。
- 以進度、掌握感、解鎖、即時回饋與可選擇深挖為主。
