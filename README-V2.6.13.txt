V2.6.13 — ACTUAL TRADE HUB / QUICK ENTRY / BACKSTAGE CLOSE
Date: 2026-09-03

延續 V2.6.12。這版專門把「看到標的 → 實際建倉 → 集中管理 → 結案留後台」整理成一致流程。

1) 觀察頁新增「已建倉」
- 放在「觀察」頁上方。
- 預設關閉，不搶畫面；右側只顯示目前 ACTIVE 筆數。
- 所有實際建倉，只要後端狀態仍為 ACTIVE，都集中顯示在這裡。
- 不依賴標的還在不在 B 級、A/B/C、觀察排行或建議排行，所以建倉後不會因排名移出而找不到。
- 展開後可看到成本、當下價、TP1/TP2、SP1/SP2、保證金、槓桿、名義倉位與估算即時損益。

2) 每一筆已建倉可展開「結案」
- 每筆實倉本身也是可展開的小卡。
- 展開後右下顯示小型「結案」標籤。
- 按結案會要求一次確認，避免誤觸。
- 結案後從「觀察 → 已建倉」移除，後端 Actual Trade / 績效 / CSV / Railway Volume 歷史仍保留，不刪除資料。

3) 排行 / 建議 / 觀察全部補小型「建倉」
- 建議排名卡：標的旁新增小型「建倉」。
- 觀察排行卡：標的旁新增小型「建倉」，原本較大的實際建倉按鈕隱藏，避免重複。
- A/B/C 手動作戰清單：標的旁也新增同樣的小型「建倉」。
- 同一標的＋同方向已有 ACTIVE 實倉時，小格自動改成「已建倉」並停用，避免重複追蹤。

4) 共用快速建倉視窗
- 從建議 / 觀察 / A-B-C 任一處按「建倉」都開同一個精簡視窗。
- 自動嘗試帶入目前成本、TP、SP、signalKey、策略與市場狀態。
- 可以手動修改成本、TP1、TP2、SP1、SP2、保證金、槓桿與數量。
- 新快速建倉的預設槓桿改為 3x；之後會記住你最後一次輸入的保證金 / 槓桿。
- 儲存成功後立刻出現在「觀察 → 已建倉」。

5) 不影響既有學習 / 通知
- V2.6.12 幣圈＋美股共同學習保持不變。
- HIGH / NORMAL、A/B/C、ABC Shadow、Structure、交易員通知白名單不變。
- 既有「監控 → 我的實際建倉」仍保留；V2.6.13 是另外在「觀察」提供更集中、預設收起的實倉入口。

部署
- 解壓 ZIP，把裡面的檔案上傳 GitHub repo 根目錄。
- 同名檔案 Replace，新檔 Add。
- Railway Variables / Volume 不要刪。
- Deploy 完成後，手機 PWA 完全關閉再打開一次，讓新版靜態資源接手。
