V2.6.9 — 觀察手動建倉 + 頁面鎖定

1. 觀察頁也能「實際建倉」
- 每一張觀察卡新增「實際建倉」。
- 不必等到 B 級 / 通知級才能手動記錄你的實際建倉。
- 沿用既有成本、TP1、TP2、SP1、SP2、保證金、數量、槓桿欄位與後端 TP/SP 即時追蹤。
- 開啟建倉視窗後會固定該筆資料；即使填寫途中標的離開觀察榜或 B 級，表單不會被清掉，仍可完成儲存。
- 若標的離榜，視窗保留開啟時的行情資料；後端儲存後照常進入實際建倉績效追蹤。

2. 小型「鎖定」標籤
- 頁籤下方右側新增小型鎖頭標籤，不搶畫面。
- 點一下鎖定目前頁面；再次點擊解除。
- 鎖定後：重新整理 / 再開 APP 會回到該頁，且停用左右滑誤切頁。
- 仍可直接點上方頁籤切頁；若已鎖定，鎖會跟到你新點的頁面。
- 通知深連結仍可正常打開指定監控頁，不會因鎖定漏掉通知入口。

3. 不改交易核心
- HIGH / NORMAL / VALID 門檻不變。
- Structure V2 / Shadow / 影子戰術學習不變。
- Railway Hobby / Egress 優化不變。
- Volume / Variables 不需修改。
