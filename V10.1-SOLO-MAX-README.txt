V10.1 SOLO MAX — 多策略自動觀察 / 通知 / 績效引擎
版本：V10.1.0
用途：單人使用；Binance USDT 永續為主資料源，Bybit / OKX 做備援與跨所交叉驗證。

這版的核心改變
1. 「測試」改為「觀察」
   - 頁籤：觀察
   - 大標題：觀察中
   - 不再把整個系統稱為「回踩測試」，因為現在同時跑多種策略。

2. 五套策略同時競爭
   - 順勢回踩不破
   - 突破 → 回測確認
   - 流動性掃盤 → 收回反轉
   - 強勢動能續攻
   - 區間極值反轉
   系統依市場 Regime、5m/15m/30m/1h 趨勢與動能、OI、Taker、大戶、深度、Funding、ADL、BTC/ETH、跨所資料等，自動選出「目前最接近完成」的策略。

3. 觀察完成度 = XP 經驗條概念
   - 每套策略有 0–100% 完成度。
   - #1 / #2 / #3… 不是單純市場熱度排行。
   - 排名優先由「完成度」主導，再疊加校準勝率與動態品質。
   - 目前權重：完成度 50% + 校準勝率 40% + 動態品質 10%。
   - 100% 代表策略條件完成並通過進場確認，不代表保證獲利。

4. 通知邏輯
   - 只有最佳策略 Ready，且資料完整度 / 可信度 / Spread / ADL / Funding / 追價 / 跨所逆向等風險閘門通過，才進入通知。
   - HIGH / NORMAL 仍維持分級。
   - 進場通知會記錄策略名稱，之後績效可按策略拆開比較。

5. 多策略結構保護
   - 舊的「回踩失效位」不再能直接淘汰整個標的。
   - 只有價格深度失效，且 15m + 30m/1h 同步反向，才判定全策略結構失效。
   - 避免某一套策略失效，卻錯殺另一套正在形成的策略。

6. UI
   - 上方大頁籤黑色底移除，改透明底 + 金色底線表示目前頁面。
   - iPhone Safe Area 保留。
   - 觀察卡顯示最佳策略、完成度條、校準勝率、五策略各自進度與下一步。

7. 績效
   - 真正成功送出的進場通知才建立績效樣本。
   - 追蹤 5 / 15 / 30 / 60 / 90 / 240 分鐘、MFE / MAE、1R / SL、PF、Expectancy、Brier / Calibration。
   - 新增按 strategyId / strategyLabel 的績效拆分，可比較五套策略實戰表現。
   - 歷史績效 ledger 仍沿用 V10.0 key，避免小版本更新切斷既有樣本。

部署

重要
- ROOT 包保留上一版 VAPID 檔案，避免沒有環境變數時導致 iPhone Push 訂閱失效。
- 不把缺資料硬補成 0；無可靠來源就保留空白並降低完整度 / 可信度。
- 這是交易監控與通知工具；「100% 完成度」是條件完成度，不是交易勝率。
