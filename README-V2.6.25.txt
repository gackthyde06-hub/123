V2.6.25 — System Growth Readability + Expandable Learning

這版只優化「系統養成」前端呈現，不改交易邏輯、Shadow 門檻、通知、實際建倉、Railway Variables 或 Volume。

改善：
- 手機字體整體放大：標題、數值、說明、任務、成長紀錄都提高可讀性。
- 角色狀態改成 6 個可展開項目；點開直接看到該能力的 Shadow 學習資訊與真實數據。
- 方向辨識：最強模式 / Train 命中率 / Wilson 保守下界 / 有效樣本。
- 執行品質：Forward 樣本 / OOS Net PF / 穩定窗口 / 成長階段。
- 成本效率：Train Net PF / Net Expectancy / Forward Net PF。
- Regime 適應：時間穩定分 / 正向時間窗 / 最強策略資產。
- 穩定度：穩定度分數 / 正向窗口 / OOS 樣本 / OOS PF。
- 風險過濾：Top2 集中度 / 去 Top2 PF / 集中度分數 / 警告數。
- 主線任務也可展開，看每項任務目前的學習依據，不再只有一條進度條。
- 展開狀態會記住，背景 15 秒刷新不會把你正在看的內容自動關掉。
- 角色狀態、成長進度、主線任務、每日訓練、紀錄、解鎖條件全部改成一致的暖灰玻璃 / 香檳金 / 冷藍層級，不再用一塊塊死黑背景。
- 成長進度新增「完成 / 現在 / 未解鎖」狀態與現在正在做什麼的簡短說明。
- 不使用圖片素材、不載入 V2.6.23 圖片層，避免風格不一致與重疊。
