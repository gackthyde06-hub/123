V2.6.13.1 HOTFIX 上傳方式

1. 解壓 ZIP。
2. 全部檔案上傳到 GitHub repo 根目錄。
3. package.json、prepare-ui.mjs 等同名檔案選 Replace；start-safe-v26131.mjs 選 Add。
4. 不要改 Railway Variables。
5. 不要刪除或重建 Railway Volume。
6. GitHub 更新後讓 Railway 自動重新部署。

關鍵確認：Railway Start Command 若有手動覆寫，應留空讓 package.json 生效；若你曾手動設定 Start Command，改為：node start-safe-v26131.mjs
